# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.x     | ✅ Yes    |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via GitHub's private [Security Advisories](https://github.com/DOWNEY7/terrabuilder/security/advisories/new) feature.

Include as much of the following as possible:

- Type of issue (e.g. XSS, dependency vulnerability, etc.)
- Full paths of affected source files
- Steps to reproduce
- Proof-of-concept or exploit code (if available)
- Impact assessment

You should receive a response within **48 hours**. If the issue is confirmed, a patch will be released as soon as possible.
